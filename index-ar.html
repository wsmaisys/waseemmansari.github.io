تصميم الأنظمة المستقلة والوكيلة

الذكاء الاصطناعي الإنتاجي يتجاوز مجرد التلقينات البسيطة. أقوم بتصميم خطوط أنابيب معالجة ذاتية الإصلاح، وحلقات معالجة الأخطاء الذكية، وأطر تنسيق الوكلاء المتعددين عبر LangGraph، وخوادم Model Context Protocol (MCP) المعيارية لتنفيذ إجراءات مؤتمتة وموثوقة.

🕸️

رسوم المعرفة البيانية الهجينة

ما بعد البحث المتجهي التقليدي: هيكلة استعلامات Neo4j Cypher للبحث السيمانتيكي متعدد المستويات مع مراعاة الخصوصية.

📈

التنبؤ بالسلاسل الزمنية والطلب

نماذج تنبؤية متقدمة (TSB & Croston) مع محاكاة Monte Carlo لتحسين مستويات المخزون وأنظمة ERP.

🛡️

هندسة MLOps وأمن البيانات (GDPR)

خدمات FastAPI السريعة، طوابير مهام Celery + Redis، حاويات Docker على Google Cloud Run و Azure. رصد كامل للأداء والكمون عبر LangSmith و WandB مع الامتثال للائحة GDPR.
